Hostel Management System

A web-based Hostel Management System developed using Django to simplify hostel administration and improve student accommodation management. This system helps manage student records, room allocation, complaints, fee details, and hostel activities efficiently.

Project Overview

The Hostel Management System is designed to automate the manual process of managing hostel operations. It provides separate functionalities for administrators and students, making hostel management faster, organized, and user-friendly.

Features

1.Admin Module
- Admin Login Authentication
- Manage Hostel Rooms
- Managing menu
- Updating Announcements
- Room Allocation Management
- Complaint Management
- Fee Management
- Dashboard with Hostel Statistics

2.Student Module
- Student Registration & Login
- Browse rooms
- View Room Details
- Submit Complaints
- View Fee Status
- View Menu
- View Announcements
